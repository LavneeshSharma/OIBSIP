# 🚗 Car Price Prediction Using Machine Learning

## 🎯 Objective
Build a machine learning model to predict used car prices using regression techniques.

---

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

---

## 📂 Dataset Features
- Year
- Present Price
- Driven Kilometers
- Fuel Type
- Transmission
- Owner Type

---

## 📈 Workflow
- Data Cleaning
- Feature Engineering
- Categorical Encoding
- Exploratory Data Analysis
- Model Training
- Model Evaluation
- Model Comparison

---

## 🤖 Models Used
- Linear Regression
- Random Forest Regressor

---

## 📊 Results

### Linear Regression
- R² Score: ~0.74

### Random Forest Regressor
- R² Score: ~0.60

Linear Regression performed better due to the smaller dataset size and relatively linear relationships among features.

---

## 📌 Key Insights
- Present price strongly affects selling price.
- Older cars tend to have lower resale value.
- Simpler models can sometimes outperform complex ensemble models.
