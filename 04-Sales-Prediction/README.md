# Sales Prediction Using Machine Learning

This project predicts product sales based on advertising expenditure across different platforms such as TV, Radio, and Newspaper.

## Objective

The aim of this project is to build a machine learning model that can predict sales based on advertising budget data.

## Dataset

The dataset contains advertising spending and sales data.

Features:
- TV
- Radio
- Newspaper

Target:
- Sales

## Steps Performed

- Loaded and explored the dataset
- Checked dataset shape, columns, and missing values
- Performed exploratory data analysis
- Visualized relationships between advertising channels and sales
- Split the data into training and testing sets
- Trained regression models
- Compared model performance using evaluation metrics

## Models Used

- Linear Regression
- Random Forest Regressor

## Evaluation Metrics

- Mean Absolute Error
- Mean Squared Error
- Root Mean Squared Error
- R2 Score

## Conclusion

The project shows how advertising expenditure affects sales and how machine learning can be used to predict future sales.
