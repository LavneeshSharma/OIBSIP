# 📊 Unemployment Analysis in India

A Data Analytics project focused on analyzing unemployment trends across India during the COVID-19 period using Python and visualization techniques.

---

## 🎯 Objective

The objective of this project is to:
- analyze unemployment trends in India,
- understand the impact of COVID-19 on employment,
- perform exploratory data analysis (EDA),
- and generate meaningful insights using data visualization.

---

## 📂 Dataset

Dataset used:
- Unemployment Rate in India Dataset

The dataset contains:
- State-wise unemployment data
- Employment estimates
- Labour participation rates
- Monthly unemployment statistics

---

## 🛠️ Technologies & Libraries Used

- Python 🐍
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📈 Analysis Performed

### ✅ Data Cleaning
- Checked missing values
- Cleaned column names
- Converted date columns
- Removed unnecessary columns

### ✅ Exploratory Data Analysis
- State-wise unemployment analysis
- Monthly unemployment trends
- COVID-19 unemployment impact analysis
- Correlation analysis using heatmaps

### ✅ Visualizations
- Bar Charts
- Line Plots
- Heatmaps

---

## 📊 Key Insights

- Certain Indian states showed significantly higher unemployment rates.
- COVID-19 caused noticeable spikes in unemployment during 2020.
- Employment and unemployment showed negative correlation.
- Labour participation varied across different regions.
