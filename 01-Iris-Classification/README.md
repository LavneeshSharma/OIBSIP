# 🌸 Iris Flower Classification

A Machine Learning project that classifies Iris flowers into different species based on their physical measurements using the K-Nearest Neighbors (KNN) algorithm.

---

## 📌 Project Overview

The Iris dataset is one of the most popular beginner datasets in Machine Learning and Data Science.

This project focuses on:
- Data Analysis & Visualization
- Data Preprocessing
- Machine Learning Model Training
- Model Evaluation

The model predicts the species of an Iris flower using:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

---

## 🧠 Machine Learning Algorithm Used

- ✅ K-Nearest Neighbors (KNN)

---

## 📂 Dataset Information

The dataset contains 3 classes of Iris flowers:

| Class | Species |
|---|---|
| 0 | Setosa |
| 1 | Versicolor |
| 2 | Virginica |

Total Samples: **150**

Features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
